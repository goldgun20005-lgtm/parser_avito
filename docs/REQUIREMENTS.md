# REQUIREMENTS — Требования к решению

> Статус: **заполнено по ответам пользователя (Фаза B)**. Серверные детали — уточняются.

## 0. Ответы пользователя (зафиксировано)
| Вопрос | Ответ |
|---|---|
| Сценарий | **Надёжный 24/7, доступ для себя + нескольких друзей** (не массовая аудитория) |
| Способ развёртывания | **Docker, сборка из исходников** (не `latest`, т.к. #293) |
| Канал уведомлений | **Webhook / n8n** |
| Антиблок | **spfa.ru (cookies-сервис)** |

## 1. Целевая архитектура (вывод)
**Вариант 2 «Надёжный» + Webhook-нотификатор + n8n (слой раздачи) + spfa.ru.**
- Один 24/7 экземпляр парсера (Docker, локальная сборка), один набор ссылок.
- Парсер на каждое новое объявление шлёт **webhook (POST JSON)** → **n8n**.
- **n8n** выполняет персонализацию: маршрутизацию по друзьям, доп. фильтры, формат, кнопки, рассылку в Telegram/прочее.
- Это позволяет обслуживать «нескольких друзей» **без** мультиарендной переработки (Вариант 3).
- Антиблок: **spfa.ru** (`use_bypass_api=true`, `cookies_api_key`) + желательно серверный прокси РФ.

> Открытый дизайн-вопрос: друзья следят за **одинаковыми** поисками или у каждого **свои** ссылки?
> От этого зависит, фильтровать ли по друзьям в n8n (общий парсер) или поднимать несколько экземпляров.

## 2. Функциональные требования
- [x] Источники: список ссылок Avito (точное число — уточнить).
- [x] Частота проверки: настраивается `pause_general` (уточнить желаемую).
- [x] Канал: **Webhook → n8n** (нужна доработка `WebhookNotifier`, см. `WEBHOOK_N8N_INTEGRATION.md`).
- [ ] Фильтры: базовые есть в парсере; персональные — в n8n.
- [ ] Изменение цены: дедуп по `(id, price)` уже даёт «новое при смене цены»; историю — опционально в n8n/БД.

## 3. Нефункциональные требования
- [x] Доступность: 24/7, авто-рестарт, healthcheck, мониторинг, бэкапы.
- [x] Безопасность: секреты вне git (`.env`), non-root Docker. См. `SECRETS_MANAGEMENT.md`.
- [ ] Бюджет (прокси/spfa/VPS), RPO/RTO, часовой пояс — уточнить.
- [ ] Ресурсы сервера, ОС, архитектура (amd64/arm64), наличие Docker — уточнить.

## 4. Ограничения и допущения (из аудита)
- Антиблок обязателен (spfa.ru подключаем; прокси РФ желателен).
- Локальная сборка Docker (не `latest`, #293).
- До продакшена закрыть P0: секреты, порядок save/notify (#300), UNIQUE-дедуп, heartbeat/healthcheck.
- Webhook-нотификатор — обязательная доработка под выбранный канал.
