# WEBPANEL — Веб-панель управления

Простая админ-панель в браузере: все настройки парсера без терминала + Старт/Стоп, логи и тесты.

## Запуск

```bash
# из корня проекта, в venv с установленными зависимостями
python webpanel.py
# откроется http://127.0.0.1:8000
# другой порт/хост: python webpanel.py --port 8080 --host 127.0.0.1
```

Открой в браузере `http://127.0.0.1:8000`.

## Что умеет

| Вкладка | Что настраивает |
|---|---|
| 🔍 Поиски | список ссылок Avito, число страниц |
| 🧮 Фильтры | цена, бел./чёрный список слов, продавцы, гео, возраст, резерв/продвижение |
| 📣 Уведомления | Webhook/n8n, Telegram, VK + кнопки «Проверить» |
| 🛡 Антиблок | spfa.ru (API-ключ), прокси, смена IP, свои cookies |
| ⚙️ Поведение | паузы, ретраи, таймаут, режимы (one_time_start и т.д.) |
| ▶️ Запуск и логи | Старт/Стоп парсера, живые логи, предпросмотр `config.toml` и `.env` |

- **Сохранить** — пишет всё в `config.toml` (кнопка вверху справа).
- **Старт/Стоп** — запускает/останавливает `parser_cls.py` (graceful shutdown по SIGTERM).
- **Проверить webhook/Telegram/VK** — шлёт тестовое сообщение тем же кодом, что и боевой парсер.
- Внизу вкладки «Запуск» — готовые `config.toml` и `.env` с кнопками **Копировать/Скачать**.

## Два режима работы

1. **С backend (`python webpanel.py`)** — полный функционал: сохранение в `config.toml`,
   Старт/Стоп, логи, тесты.
2. **Просто открыть `web/index.html` в браузере** (без сервера) — работает как редактор конфига:
   заполняешь поля → вкладка «Запуск» → **Скачать** `config.toml`/`.env`. Значения сохраняются
   в браузере (localStorage). Старт/Стоп и тесты в этом режиме недоступны.

## Безопасность

- По умолчанию панель слушает **только `127.0.0.1`** (локально). Это правильно: она пишет конфиг
  и запускает процессы.
- Если нужен доступ с другого устройства — ставь **только** за reverse-proxy (nginx/Traefik) с
  HTTPS и авторизацией, либо ходи через SSH-туннель:
  `ssh -L 8000:127.0.0.1:8000 user@server` и открывай `http://127.0.0.1:8000` локально.
- Секреты, введённые в панели, попадают в `config.toml` (или `.env` при скачивании) — эти файлы
  уже в `.gitignore`-политике (см. `SECRETS_MANAGEMENT.md`), в git не коммить.

## В Docker (опционально)

Панель можно добавить отдельным сервисом или запускать рядом. Для 24/7 сам парсер удобнее
держать в контейнере (`docker-compose.prod.yml`), а панель поднимать по необходимости для
правки настроек. При желании могу добавить сервис `webpanel` в compose с проксированием.
