# SERVER_QUESTIONNAIRE — Опросник перед развёртыванием

> Статус: **Ожидаются ответы пользователя.**
> Прежде чем готовить индивидуальный план развёртывания (`DEPLOYMENT_PLAN.md`) и итоговые
> требования (`REQUIREMENTS.md`), нужно получить ответы. Ничего на сервере не устанавливается
> до согласования варианта (см. `DEPLOYMENT_OPTIONS.md`).
> Секретные значения (токены, пароли, ключи) **не присылайте в чат** — их добавим через `.env`/на сервере.

---

## A. Задача и масштаб
1. Парсер для личного использования или для клиентов?
2. Один пользователь или несколько?
3. Бесплатный внутренний инструмент или коммерческий сервис?
4. Какие товары/категории отслеживать?
5. Сколько поисковых ссылок Avito одновременно (порядок: единицы / десятки / сотни)?
6. Города/регионы?
7. Как часто проверять новые объявления (раз в N секунд/минут)?
8. Насколько критична скорость уведомления (секунды/минуты)?
9. Отслеживать только новые / изменение цены / удаление объявления?
10. Хранить ли историю изменения цены, описание, фото, телефон?

## B. Фильтры
11. Нужны белый/чёрный списки слов, фильтр по продавцу, по цене, по дате, по типу продавца, по состоянию?
12. Нужен поиск подозрительно дешёвых предложений / оценка привлекательности / поиск дублей /
    сравнение со средней ценой / авто-рейтинг / объединение нескольких запросов в подборку?

## C. Уведомления
13. Куда: Telegram (личка/группа/канал), VK, email, Webhook/n8n?
14. Уже есть Telegram-бот, Bot Token, Chat ID? (значения — не в чат)
15. Несколько получателей? Разные получатели для разных категорий?
16. Нужны кнопки в сообщении, фото, цена, старая цена, продавец, кнопка «Открыть/В избранное/Скрыть продавца»?
17. Нужен ли бот для управления фильтрами и вкл/выкл мониторинга из Telegram?
18. Нужны ежедневные отчёты; уведомления об ошибках/остановке/блокировке IP/окончании прокси-баланса?

## D. Сервер
19. Сервер уже есть или подобрать? Провайдер, страна, IP (IP — не в чат), ОС и версия?
20. CPU / RAM / диск / архитектура (amd64 или arm64)?
21. Root-доступ? Отдельный sudo-пользователь? Подключение по SSH-ключу или паролю?
22. SSH настроен? Порт изменён? Firewall настроен?
23. Установлены ли Docker и Docker Compose?
24. Есть ли другие приложения на сервере (Nginx/Traefik/Portainer/Coolify/Dokploy)?
25. Нужен ли домен/внешний веб-интерфейс/HTTPS/VPN/ограничение по IP?
26. Есть ли бэкапы, мониторинг сервера, автообновления безопасности?
27. Часовой пояс (например, Europe/Moscow)?

## E. Способ развёртывания
28. Docker или обычный Python?
29. Готовый образ или сборка из исходников? (рекомендация: сборка — из-за #293)
30. Делать форк? Планируются ли свои изменения? Нужно ли тянуть обновления upstream автоматически?
31. Нужны ли staging + production? GitHub Actions / auto-deploy по push?
32. Закрепить конкретную версию? Нужна ли возможность отката? Сколько версий конфигов хранить?
33. Где хранить секреты, SQLite, Excel/JSON, логи? Сколько дней хранить логи/результаты?
34. Выгружать ли результаты во внешнее хранилище?

## F. Прокси, cookies, устойчивость
35. Есть ли прокси? Тип (мобильный/серверный), страна, статический/ротация, ссылка смены IP, число IP, авторизация?
36. Планируете свои cookies? Можете регулярно их обновлять? Внешний сервис cookies (spfa.ru)?
37. Допустимый месячный бюджет на инфраструктуру/прокси/cookies?
38. Допустимый процент ошибок? Что делать при блокировке (стоп или ретраи)? Через сколько повторять?
39. Авто-переключение прокси? Снижать частоту при росте ошибок? Распределять ссылки между IP? Отдельный IP для Telegram?
40. Скрывать прокси/cookies из логов?

## G. Хранение данных
41. Достаточно ли SQLite или нужен PostgreSQL?
42. Сколько объявлений в день ожидается? Хранить полную историю? Нужен поиск по истории?
43. Экспорт: Excel / JSON / CSV? REST API? Веб-панель?
44. Хранить фото / raw HTML / raw JSON? Сколько хранить объявления? Авто-cleanup?
45. Резервные копии SQLite: куда (локально/S3/Backblaze/Google Drive)? Как часто? Допустимый объём потери данных (RPO)? Время восстановления (RTO)?

## H. Будущее развитие
46. Подписочный сервис? Регистрация, тарифы, лимиты, оплата, личный кабинет, админ-панель?
47. Telegram Mini App / обычный бот / веб / мобильный интерфейс / API для клиентов?
48. Раздельные запросы и уведомления на пользователя? Разделение данных? Роли admin/user?
49. Статистика использования, аналитика предложений, авто-оценка, интеграция с ИИ, авто-резюме,
    проверка подозрительности, классификация продавцов?
50. Интеграции: CRM, n8n, Supabase, Google Sheets, amoCRM/Bitrix24? Очередь задач? Максимум пользователей?
