## Версия Python
- Требуется **3.11+** (используется `tomllib` из stdlib — доступен только с 3.11; синтаксис `X | None`).
- Dockerfile: `python:3.11-slim`. CI .exe: Python **3.12**. Локально в окружении аудита: 3.11.15.
- ✅ Синтаксис всех `.py` компилируется без ошибок (`python -m compileall`).

## Отдельная проверка по запрошенным пунктам

- **Python:** 3.11+ обязателен (`tomllib`). ОК.
- **Playwright / Chromium:** нужны **только** для (а) GUI-логина в аккаунт и (б) неиспользуемого `get_cookies.py`.
  В Docker ставится `chromium-headless-shell`, но основной серверный поток (`curl_cffi`) его не использует →
  **лишний вес образа** и время сборки. На headless-VPS логин в аккаунт через браузер не выполнится.
- **Flet:** только GUI. На сервере импортируется лишь `AvitoParser.py`, который на сервере не запускают.
  В `requirements.txt` единый список → на сервер ставится всё.
- **BeautifulSoup:** обязателен (поиск встроенного JSON, парсинг просмотров).
- **HTTP-клиенты:** их **три** — `curl_cffi` (парсер), `requests` (уведомления/spfa/смена IP), `httpx` (логин/абстракция).
  Это сделано намеренно (см. `docs/DOCS.md` п.7), но увеличивает поверхность зависимостей.
- **Pydantic:** v2.9.2 — ядро валидации; главный источник падений при изменении разметки Avito.
- **OpenPyXL:** единственный реально используемый Excel-движок; семейство `pyexcel*` похоже на **мёртвые зависимости**.
- **SQLite:** stdlib (`sqlite3`), отдельной зависимости нет.
- **Библиотеки уведомлений:** отдельных SDK нет — TG/VK дёргаются напрямую через `requests`.

## Риски и общие рекомендации (без автообновления)

1. **Не зафиксированы версии `curl_cffi` и `httpx`** → недетерминированные сборки. Зафиксировать (P1).
2. **Возможные мёртвые зависимости:** `pyexcel`, `pyexcel-io`, `pyexcel-xlsx`, `PyYAML` — не найдены в импортах.
   Убрать после проверки (уменьшит вес и поверхность уязвимостей).
3. **Разделить requirements:** `requirements.txt` (сервер, без flet/playwright) и `requirements-gui.txt` (desktop).
4. **UTF-16 у requirements.txt** — пересохранить в UTF-8.
5. **Security scanning не настроен** — рекомендовать `pip-audit`/Dependabot/Trivy (P1).
6. Все выводы об уязвимостях здесь — на основе версий; **онлайн-сверка с CVE не проводилась** в этом окружении.
   Перед продакшеном выполнить `pip-audit` (см. `SECURITY_AUDIT.md`).
