### Оставшиеся проверки уровня 2 (на сервере)

План (выполнять в изолированном venv, на тестовой ссылке с малым числом объявлений, `count=1`, без агрессии):
1. `python -m venv .venv && pip install -r requirements.txt`.
2. Подготовить тестовый `config.toml` (1 узкая ссылка, без токенов, `one_time_start=true`, `save_xlsx=true`).
3. `python parser_cls.py` — проверить:
   - стартует, конфиг читается, лог `Запуск AvitoParse v3.2.15`;
   - запрос отправляется, HTML/JSON получены (`find_json_on_page` находит данные);
   - объявления извлекаются (`ItemsResponse` без `ValidationError` — **особое внимание из-за #306/#307**);
   - фильтры отрабатывают (логи `После фильтрации …`);
   - создаётся `result/avito.xlsx`, заполняется `database.db`;
   - **повторный запуск не шлёт те же объявления** (дедуп) — критическая проверка;
   - логи пишутся в `logs/app.log`; завершение корректное.
- **Ожидаемый риск:** с дата-центрового IP высока вероятность 403 от Avito → это тоже валидный
  результат (подтвердит необходимость прокси/spfa).
